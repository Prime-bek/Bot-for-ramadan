# Telegram-бот напоминаний о намазе, сухуре и ифтаре

Бот отправляет сообщения:
- за N минут до выбранных событий (по умолчанию: `suhur_end`, `fajr`, `iftar`);
- точно в момент наступления времени намаза/сухура/ифтара.

## 1) Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 2) Настройка

1. Скопируйте `.env.example` в `.env`.
2. Заполните:
   - `BOT_TOKEN` — токен вашего Telegram-бота;
   - `CHAT_ID` — id чата/пользователя, куда отправлять напоминания;
   - `TIMEZONE` — часовой пояс (например `Asia/Tashkent`).

## 3) Заполните расписание

Создайте `schedule.csv` (можно начать с `schedule.example.csv`).

Обязательная колонка:
- `date` в формате `YYYY-MM-DD`

Дополнительные колонки времени (формат `HH:MM`):
- `suhur_end`, `fajr`, `dhuhr`, `asr`, `maghrib`, `isha`, `iftar`
- можно добавить и свои названия колонок (бот тоже обработает их).

Пример:

```csv
date,suhur_end,fajr,dhuhr,asr,maghrib,isha,iftar
2026-02-20,05:44,05:49,12:38,15:55,18:15,19:28,18:15
```

## 4) Запуск

```bash
python bot.py
```

## Полезные параметры в `.env`

- `REMINDER_MINUTES=10` — за сколько минут напоминать.
- `REMINDER_EVENTS=suhur_end,fajr,iftar` — для каких событий делать предварительное напоминание.
- `CHECK_INTERVAL_SECONDS=30` — как часто проверять текущее время.
